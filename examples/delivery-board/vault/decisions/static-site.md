# Aplicação estática com dados revisados

[Decisões](index.md) · [Feature](../features/delivery-board/index.md) · [Pages](../integrations/github/pages/index.md)

Decisão vigente, aprovada em 2026-10-03: HTML, CSS e módulos JavaScript com dados fictícios em JSON.
A lista demonstra critérios e provas; estado e busca ajudam a localizar a entrega. Mudanças passam por PR.

Uma API exigiria hospedagem de processo. Um produto real exigiria escolher um projeto e revisar dados
publicáveis. O quadro permite provar o rito aprovado com servidor estático e sem credenciais de usuário.
Não haverá login, backend, banco, edição colaborativa, relatório exportável ou IA em produção nesta frente.

O pacote permite apenas seis arquivos conhecidos e seu manifesto; o vault público permanece navegável
no GitHub. Fontes locais, transcrições, recibos e backups ficam fora da publicação. Produção depende de
observação externa da revisão publicada, não dos estados fictícios de data.json.
