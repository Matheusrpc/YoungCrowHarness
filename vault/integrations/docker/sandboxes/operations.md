[Integração](index.md) · [Implementação](implementation.md)

| Ambiente | Dependência | Evidência em 2026-10-04 UTC | Estado |
|---|---|---|---|
| Host de desenho | Windows 11 x64 | Hipervisor ativo, WHP desabilitado, `sbx` e WSL ausentes | Preparação pendente |
| Executor de prova | Docker Sandboxes local | Não criado; nenhum login novo | Não executado |
| Produção | Adaptador YoungCrow | Código de produto não alterado | Não implantado |

Instalação futura exige artefatos oficiais verificados e os pré-requisitos do sistema. Ativação
administrativa e reinício têm janela escolhida pelo operador; não reiniciar automaticamente.
Conta Docker e logins são feitos pelos fluxos oficiais. O harness não registra valores de tokens.

O retorno do trial restaura o repositório, não desinstala runtime do sistema nem revoga logins.
A remoção futura lista e confirma somente recursos próprios; não apaga componentes compartilhados,
contas ou recibos. Não usar reset global. Recursos de cloud, Docker Desktop e governança paga
não são ativados por este desenho. Sem runtime certificado, nenhum despacho de modelo é liberado.
