# Integrações / Integrations

[Vault](../index.md) · [Capacidades / Capabilities](../capabilities/index.md)

Fornecedores e serviços são acrescentados ao iniciar uma integração. Consulte o microíndice do serviço para finalidade, responsável, estado e próxima ação.
Providers and services appear when an integration is initialized. The service index records purpose, owner, state and next action.

Na raiz do projeto / from the project root:

```bash
python3 scripts/integrations.py init --provider example --service payments --run first-contract
```
